An entry for the [One-Line Office Joke Laugh-Off](https://make.fun/bounty/u-suzy-one-line-office-joke-laugh-off-f574ac73) on make.fun.

## The joke

> The new hire's badge photo is already in the alumni newsletter.

## How it works

`main.py` writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt`. It takes no
input, uses no network, and running it twice writes the same bytes.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
